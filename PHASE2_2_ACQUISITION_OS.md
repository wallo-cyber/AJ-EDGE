# نوفافيرك Phase 2.2 — Acquisition OS

Primary operating model:
Market Signal → Project Candidate → Verified Project → Access Map → Work Package → Pursuit → RFQ/Bid → Won.

Implemented:
- Acquisition Command Center replaces the old daily CRM view.
- Project Radar converts verified external signals into Project Candidates with a human gate.
- Pursue Board ranks actual project pursuits.
- Access Map inside every project shows Owner / Consultant / Main Contractor / Supplier as routes into the project.
- Route-to-Revenue remains explicit and project-specific.
- Project Candidate creation never auto-verifies the project.
- Existing CRM pages remain available as supporting tools.
- Primary navigation now reflects acquisition work: Command Center, Project Radar, Pursuits, Market Network, Results.
- No fabricated project/company/contact/signal data has been added.
